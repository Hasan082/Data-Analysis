# Capstone Project Structure

## 1. **Data Visualization**

* **Purpose**: Contains visualizations for understanding the data better using different chart types (e.g., bar charts, line graphs, scatter plots, etc.).
* **Use**: Explore and visualize the relationship between different variables in the dataset.

## 2. **Data Wrangling**

* **Purpose**: Includes scripts or notebooks for cleaning and transforming raw data into a usable format.
* **Use**: Prepare the data by handling missing values, outliers, and ensuring that it is ready for analysis or model building.

## 3. **Finding\_Correlation.ipynb**

* **Purpose**: Jupyter notebook focused on calculating correlations between various features in the dataset.
* **Use**: Perform statistical analysis to identify relationships between variables (e.g., Pearson correlation).

## 4. **Scatter\_Plot\_rdms.ipynb**

* **Purpose**: Contains a scatter plot for visualizing relationships between two variables.
* **Use**: Helps in understanding how two variables are correlated visually by plotting them on a 2D graph.

## 5. **Stacked\_Charts.ipynb**

* **Purpose**: Jupyter notebook for creating stacked charts, useful for comparing multiple categories.
* **Use**: Visualize multiple categories in the same chart, useful for understanding the distribution of data across different groups.

## 6. **example1.txt**

* **Purpose**: Text file that may contain sample input/output data or API request/response examples.
* **Use**: Provide examples of data being handled, such as GET and POST requests.

## 7. **github-job-postings.xlsx**

* **Purpose**: Excel file containing job posting data scraped from GitHub or other sources.
* **Use**: Analyze job postings, companies hiring, required skills, etc.

## 8. **image.png**

* **Purpose**: Image file, possibly a chart or a visualization that was generated in one of the notebooks.
* **Use**: Can be used in reports or presentations to show visual results of data analysis.

## 9. **languages.db**

* **Purpose**: SQLite database containing data related to programming languages or other project-related information.
* **Use**: Store structured data to be used for analysis or reporting, such as information about popular programming languages.

## 10. **popular-languages.csv**

* **Purpose**: CSV file that likely contains data on popular programming languages or technologies.
* **Use**: Used for data analysis or visualization to understand trends in technology usage.
