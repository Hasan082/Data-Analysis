# Data Analysis Training from IBM - Capstone Project Structure

## 1. **Data Visualization**

* **Purpose**: Visualizations using various chart types (e.g., bar charts, line graphs, scatter plots) to explore relationships between variables.
* **Use**: Understand data patterns and insights through different visualizations.

## 2. **Data Wrangling**

* **Purpose**: Scripts and notebooks for cleaning and transforming raw data into a usable format.
* **Use**: Prepare datasets by handling missing values, outliers, and data transformations for analysis.

## 3. **Finding_Correlation.ipynb**

* **Purpose**: Jupyter notebook for calculating correlations between dataset features.
* **Use**: Perform statistical analysis (e.g., Pearson correlation) to identify relationships between variables.

## 4. **Sales Analysis (`sales_data.xlsx`)**

* **Purpose**: Excel file containing sales data for analysis.
* **Use**: Analyze sales performance, trends, growth, and identify top-performing products or regions.

## 5. **Visualization Folder**

### 1. **Area Plots, Histograms, and Bar Charts (`Area_Plots_Histograms_and_Bar_Charts.ipynb`)**
   - **Purpose**: Examples of creating area plots, histograms, and bar charts for data visualization.
   
### 2. **Basic Plotly Charts (`Basic_Plotly_Charts.ipynb`)**
   - **Purpose**: Demonstrates interactive charts using Plotly.
   
### 3. **Flight Delay Time Statistics Dashboard (`Flight_Delay_Time_Statistics_Dashboard.py`)**
   - **Purpose**: Python script for visualizing flight delay statistics.

### 4. **Waffle Charts (`Waffle_Charts.ipynb`)**
   - **Purpose**: Shows how to create waffle charts and other visualizations.

### 5. **GeoJSON Files (`world_countries.json`)**
   - **Purpose**: Used for geospatial visualizations like choropleth maps.

## 6. **Data Wrangling and EDA Folder**

### 1. **Exploratory Data Analysis (`Exploratory_Data_Analysis.ipynb`)**
   - **Purpose**: Jupyter notebook for performing exploratory data analysis (EDA) and calculating key metrics.

### 2. **Automobile Dataset (`automobileEDA.csv`)**
   - **Purpose**: Dataset for creating dataframes and performing exploratory analysis on automobile data.

### 3. **Laptop Pricing Dataset Wrangling (`laptop_pricing_dataset_wrangling.ipynb`)**
   - **Purpose**: Clean and transform the laptop pricing dataset for analysis.

## 7. **Model Development Folder**

### 1. **README.md**
   - **Purpose**: Documentation for model development, explaining the process and steps.

### 2. **Automobile Dataset (`automobile.csv`)**
   - **Purpose**: Dataset used for building machine learning models to predict automobile attributes.

### 3. **Develop Prediction Models (`develop_prediction_models.ipynb`)**
   - **Purpose**: Jupyter notebook for creating, training, and evaluating prediction models.

## 8. **Socioeconomic Indicators in Chicago**

   
### 1. **Socioeconomic Database (`socioEconomicData.db`)**
   - **Purpose**: SQLite database containing raw data on income, employment, housing, and education.

### 2. **Socioeconomic Data Analysis (`socioEconomicData.ipynb`)**
   - **Purpose**: Jupyter notebook for performing analysis and visualization of Chicago's socioeconomic indicators.


## Summary

This project folder structure provides a well-organized approach to data analysis, visualization, and model development. It covers the entire data pipeline—from wrangling and cleaning the data to building predictive models and generating insights through various visualizations and interactive dashboards. The socioeconomic analysis section specifically focuses on exploring and analyzing Chicago's socioeconomic data to identify key trends and insights.
